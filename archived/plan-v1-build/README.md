# The v1 build, as planned

[PLAN.md](PLAN.md) is the v1 build plan as it stood when the build finished (2026-09-27): the starting point, the target layout, the build rules, every milestone's plan and done-when, the unattended build loop and the morning checklist. It lived in `plan/`, so its links are relative to that folder.

[decisions.md](decisions.md) is ARCHITECTURE.md's full decision log up to the same day. Neither is kept current: status and open items are in [plan/PLAN.md](../../plan/PLAN.md), and the live decisions in [plan/ARCHITECTURE.md](../../plan/ARCHITECTURE.md).

[status.md](status.md) has the finished and superseded milestone rows that left `plan/PLAN.md`, and [decisions.md](decisions.md) also has the superseded rows that left ARCHITECTURE.md's log later.
