# Legacy Plan Archive

This file used to track the 0-to-1 Bun/Web/BLE prototype plan. That plan is no longer the active production roadmap.

Current production planning is in the repo root `PLAN.md`. The active app is the Swift macOS project in `app/`; the active firmware is `src/outputs/esp32/`.

The old prototype remains useful as reference material for:

- TypeScript schemas in `schema/`
- Bun reducer and web output tests in `tests/`
- archived BLE experiments in `archive/`

Do not use this file as the source of truth for current architecture or release work.
